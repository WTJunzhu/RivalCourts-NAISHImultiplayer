纵横（RIVAL COURTS）快速规则参考
改编自《内侍（Naishi）》· Merle Editions 2024
======================================================

游戏概述
--------
2至7人战国主题桌游，改编自日本双人桌游《内侍》。每位玩家从无名白板起手，
竞相招揽人才、积累势力、抢先宣认七国之一，最终以最高得分称霸。

场地规格（三个区域格数完全一致）
--------------------------------
  2至3人：庙堂5格 / 密室5格 / 列国英才5格，君主位在位置3（正中）
  4至6人：庙堂7格 / 密室7格 / 列国英才7格，君主位在位置4（正中）
  7人  ：庙堂9格 / 密室9格 / 列国英才9格，君主位在位置5（正中）

庙堂 = 明阵，所有牌公开，人人可见。
密室 = 暗阵，所有牌隐藏，仅自己可见。
列国英才 = 公共牌池，每格一叠，顶牌朝上，被取后下张翻开。

开局状态
--------
  所有玩家庙堂和密室全为荒地牌（负分填充）。
  每人持有3枚使节代币（魏国玩家另加1枚，若已宣魏）。
  每人随机抽取2张史书卡，隐藏手持（宣国后才能打出）。
  场中央摆放7枚国家令牌：秦 齐 楚 赵 魏 韩 燕。
  牌库中君主牌数量等于玩家人数，每人最多持有1张。

基础牌类型（共10种）
--------------------
  荒地  白色  持有2张 -5分；3张以上 -15分
  农田  黄色  庙堂中相邻成对 +8分；连续4张以上 +30分
  谋士  青色  基础 +5分；与君主牌直接相邻额外 +6分
  君主  金色  庙堂中央位置 +12分；其他位置 +4分（特殊：免疫一切强制转移）
  骑兵  赤色  仅在密室得 +8分；庙堂中0分
  旌旗  橙色  仅在庙堂得 +8分；密室中0分
  关隘  灰色  单张 -5分；集齐3张 +30分
  城邑  紫色  庙堂最左端或最右端位置 +10分；其他位置 +4分
  游侠  绿色  密室中每有1种不同牌类型 x4分（上限40）
  玉璧  白/金  密室 +15分；庙堂 +5分；被强制转移时原持有者额外 +5分

五大行动（每回合选一）
----------------------
  一、招贤纳士
      从列国英才取一张牌，替换己方庙堂或密室同编号位置的牌（旧牌入弃堆）。
      可附加：消耗1枚使节，额外执行"调位"（交换任意两张牌位置）
                            或"清除"（移除列国英才任意2张牌）。
      注：宣国后庙堂中央位置锁死，不可替换。

  二、颁旨
      选择一名非结盟玩家，消耗1枚使节（永久留在颁旨格，不可召回），
      与目标同编号位置的牌互换（庙堂对庙堂，或密室对密室）。
      例外：若正与目标开战，使节改为普通消耗（可召回）。
      禁止：任何人的君主牌均不可被颁旨。

  三、使节归朝
      收回所有非永久消耗的使节代币。
      （颁旨格上的永久使节不可召回，秦国宣国后例外。）

  四、宣国（核心行动）
      同时满足以下三项方可宣国：
        1. 庙堂中央位置有君主牌
        2. 满足目标国家的专属激活条件（见下方"七国设定"）
        3. 目标国家尚未被他人宣认
      宣国流程：宣布国家 → 其他玩家核实 → 取走国家令牌 → 能力即刻生效。
      宣国不可逆：宣国后无法取消，庙堂中央位置永久锁定。
      史书卡解锁：宣国后，之前无法使用的史书卡现在可以打出了。

  五、称霸
      触发游戏结算。其余玩家各再行动一轮后进入计分。
      触发条件：列国英才中耗尽的位置数 >= 规定值
        2人游戏：2叠  3至4人：3叠  5至6人：4叠  7人：5叠

史书卡（每人开局随机抽2张，宣国后才能打出，每张只用一次）
----------------------------------------------------------
  合纵之盟  与任意玩家强制结盟，本回合双方免疫颁旨
  连横破盟  解除场上任意两名盟友的联盟，并从其中一方取一张非君主牌
  围魏救赵  强制玩家A将庙堂非君主牌给玩家B，你从列国英才免费取一张
  负荆请罪  单方面结束与某玩家的战争，无需使节，对方获 +3分
  远交近攻  与最远玩家结盟，向相邻玩家宣战，两个外交行动均免费
  纵横家    本回合执行两次常规行动
  反间计    强制某玩家公开密室至下回合结束，你额外执行一次招贤纳士
  胡服骑射  结算时本局密室骑兵得分翻倍（与赵国能力不叠加）

七国设定（激活条件 + 专属能力）
--------------------------------
  秦  条件：颁旨格有>=2枚永久使节（累计颁旨2次）
      能力：颁旨使节改为普通消耗（可召回）

  齐  条件：庙堂与密室合计持有>=5种不同牌类型
      能力：每轮开始可偷看任意对手密室一张牌

  楚  条件：庙堂+密室合计有>=3张农田
      能力：农田牌每张额外 +2分

  赵  条件：密室中有>=2张骑兵
      能力：骑兵牌得分翻倍

  魏  条件：当前有>=1个结盟关系
      能力：宣国时立即获得1枚使节

  韩  条件：庙堂+密室合计有>=2张关隘
      能力：持有关隘牌不扣分（集齐3张仍可 +30分）

  燕  条件：密室中有>=4种不同牌类型
      能力：游侠牌每个种类额外 +3分

  注：4至7人游戏建议将齐（>=5种 -> >=6种）和燕（>=4种 -> >=5种）各上调一档。

外交系统
--------
  修好（默认）：正常颁旨，永久消耗使节。
  结盟        ：双方各消耗1枚使节同时宣布。不可对盟友颁旨；可借用盟友使节。
  开战        ：任意一方在己方回合宣战，无即时代价。对敌颁旨改为普通消耗。

  背盟（结盟 -> 修好）：一方单方宣布，消耗1枚使节，受害方 +3分。
  停战（开战 -> 修好）：一方消耗2枚使节求和，需对方同意。

  战争结算：游戏结束时，每对开战玩家比较总分，胜者 +5分，败者 -5分。

得分来源
--------
  庙堂牌得分（含国家专属加成）
  密室牌得分（含国家专属加成）
  战争胜利 +5分 / 失败 -5分
  被背盟 +3分
  玉璧被强制转移 +5分

  平局裁决（依次比较）：
    1. 庙堂中不同牌种类数（多者胜）
    2. 剩余使节代币数（多者胜）
    3. 骰子决定

关键特殊规则提醒
----------------
  * 君主牌免疫一切强制转移（颁旨、史书卡均无效）
  * 每人最多持有1张君主牌
  * 宣国后庙堂中央位置永久锁死，无法改变
  * 史书卡开局即可查看，但必须宣国后才能打出
  * 国家令牌一旦被取走，其他玩家不得再宣认该国
  * 游戏结束时未宣国的玩家以白板身份参与计分，无国家加成
