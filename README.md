### 核心机制概述

每位玩家持有 **10 张牌**，分为两个区域（各 5 张，位置编号 1–5）：
- **明阵（Line）**：5 张公开牌
- **暗阵（Hand）**：5 张隐藏牌

桌中央**河流（River）**：5 个位置，每位置一叠，顶牌朝上，取走后下张翻开。

**四大行动（每回合选一）：** 发展（取牌替换）、颁布（永久消耗使者与对手互换）、召回（取回使者）、宣告（触发结算）。

胜利条件：总得分更高者胜；平局比颜色种类数。

## 二、设计理念

### 为何选择战国？

战国时期（公元前 475–221 年）是中国历史上最精彩的博弈时代：
- **七雄并立**，天然适配 2–7 人游戏
- **合纵连横**，外交博弈呼应多人颁旨行动的目标选择困境
- **招贤纳士**，对应原版核心机制"发展"
- **庙堂密室**，公开与隐藏的两面性契合明阵/暗阵设计
- **典故丰富**，完璧归赵、围魏救赵等直接转化为特殊卡牌

### 核心设计目标

1. **保留原版节奏**：回合快、决策精，不额外增加流程负担
2. **宣国是中期目标**：争抢君主牌、积累激活条件、卡位抢先宣国，构成游戏中段的主要张力
3. **外交是动态变量**：结盟/开战改变行动代价，联盟随时可能崩盘
4. **宣国后不可逆**：承诺带来约束，也带来收益，是全局最重要的单次决策
5. **史书卡是宣国的奖励**：开局可见但不可用，驱动玩家根据手牌制定宣国方向

## 四、场地规格（统一缩放）

庙堂、密室、列国英才三个区域的位置数**完全一致**，随玩家人数统一缩放：

| 人数 | 庙堂位置数 | 密室位置数 | 列国英才位置数 | 君主位编号（中央） |
|------|-----------|-----------|--------------|-----------------|
| 2–3 人 | 5 | 5 | 5 | 位置 **3** |
| 4–6 人 | 7 | 7 | 7 | 位置 **4** |
| 7 人 | 9 | 9 | 9 | 位置 **5** |

**君主位**永远是庙堂正中央位置，编号随格数自动确定，所有计分规则中提到"中央位置"均指此格。

```
[ 1 ] [ 2 ] [ 3 ] [ 4 ] [★5 君主位] [ 6 ] [ 7 ] [ 8 ] [ 9 ]
```

## 五、核心组件

### 5.1 庙堂（明阵，公开区）

每位玩家的庙堂位置数见上方统一规格表，所有牌面朝上，所有人可见。初始全为荒地牌。

### 5.2 密室（暗阵，隐藏区）

与庙堂同格数，牌面朝下，仅本人可见。初始全为荒地牌。

### 5.3 列国英才（河流）

桌子中央公共牌池，与庙堂/密室同格数。每格一叠牌，顶牌朝上，取走后下一张翻开。

### 5.4 使节代币

每位玩家开局持有 **3 枚使节代币**，是执行附加行动和外交操作的核心资源。

### 5.5 外交关系板

公共展示板，记录每对玩家之间的外交状态（初始全为"修好"）。

### 5.6 七国令牌

场中央摆放 7 枚国家令牌（秦、齐、楚、赵、魏、韩、燕）。成功宣国后，取走对应令牌置于己方区域。**被取走的令牌代表该国已被宣认，任何人不得再选。**

### 5.7 史书卡

每位玩家开局获得 **2 张随机史书卡**，隐藏持有。

> **重要限制**：史书卡**只有在宣国之后才能打出**。开局即可查看手牌，可根据史书卡内容规划宣国方向——但在宣国之前，史书卡只是潜在的战略储备，无法使用。

## 六、卡牌设计

### 6.1 基础牌（10 种）

计分规则中所有位置描述均以**相对位置**表述，适用于 5、7、9 格三种规格：

| 牌名 | 颜色 | 计分规则 |
|------|------|---------|
| **荒地** | 白 | 持有 2 张 −5 分；3 张以上 −15 分 |
| **农田** | 黄 | 庙堂中相邻每对 +8 分；连续 4 张以上 +30 分 |
| **谋士** | 青 | 基础 +5 分；与**君主牌直接相邻** 额外 +6 分 |
| **君主** | 金 | 在庙堂**中央位置（君主位）** +12 分；其他位置 +4 分 |
| **骑兵** | 赤 | 仅在**密室**得 +8 分；庙堂中 0 分 |
| **旌旗** | 橙 | 仅在**庙堂**得 +8 分；密室中 0 分 |
| **关隘** | 灰 | 单张 −5 分；集齐 3 张 +30 分 |
| **城邑** | 紫 | 在庙堂**最左端或最右端**位置 +10 分；其他位置 +4 分 |
| **游侠** | 绿 | 密室中每有 1 种不同牌类型 ×4 分（上限 40） |
| **玉璧** | 白/金边 | 密室 +15 分；庙堂 +5 分；被强制转移时原持有者额外 **+5 分** |

---

### 6.2 君主牌——特殊规则

1. **数量严格限定**：牌库中君主牌总数 = 当前玩家人数，每人最多持有 1 张
2. **免疫一切强制转移**：君主牌无法通过颁旨、史书卡或任何其他机制被强行转移
3. **宣国后位置锁定**：宣国后庙堂中央位置的君主牌**永久锁定**，不可移动或替换
4. **宣国前可自愿放弃**：主动用招贤纳士替换掉己方君主牌是合法的，但该君主牌将回到弃牌堆

---

### 6.3 史书卡（8 种，每人开局随机抽 2 张）

**史书卡只有宣国后才能打出**，代替常规行动使用，每张只能用一次。

| 史书卡 | 出处 | 效果 |
|--------|------|------|
| **合纵之盟** | 苏秦合纵六国 | 与任意一名玩家立即结盟（强制生效，双方均不消耗使节）；本回合双方免疫颁旨 |
| **连横破盟** | 张仪连横 | 强制解除场上任意两名结盟玩家的联盟；你从其中一方庙堂取一张**非君主**牌放入己方庙堂 |
| **围魏救赵** | 孙膑大梁之策 | 指定玩家 A 将庙堂某**非君主**位置的牌交给玩家 B；你从列国英才中免费取一张牌 |
| **负荆请罪** | 廉颇蔺相如 | 单方面结束你与某玩家的战争，无需消耗使节；对方获得 +3 分补偿 |
| **远交近攻** | 范雎入秦 | 与回合顺序最远的玩家结盟，同时向回合顺序相邻的玩家宣战；两个外交行动均不消耗使节 |
| **纵横家** | 苏秦/张仪双绝 | 本回合可执行两次常规行动 |
| **反间计** | 战国间谍 | 强制某玩家公开密室全部牌直至下一回合结束；你可额外执行一次招贤纳士 |
| **胡服骑射** | 赵武灵王 | 结算时本局密室中所有骑兵牌得分翻倍（与赵国专属能力不叠加） |

## 七、五大行动

每回合，当前玩家从以下**五种行动中选择一种**：

---

### 行动一：招贤纳士

从列国英才中取一张牌，替换庙堂或密室**同编号位置**的旧牌（旧牌入弃牌堆）。

**可附加**（消耗 1 枚使节）执行以下一项：
- **调位**：交换庙堂、密室或列国英才中任意两张牌的位置
- **清除**：从列国英才移除任意 2 张牌（翻开下层牌）

> 宣国后庙堂中央位置永久锁定，该位置不可通过此行动替换。

---

### 行动二：颁旨

1. 选择一名**非结盟**玩家为目标
2. 消耗 1 枚使节，**永久留在颁旨格**（无法召回）
   - **例外**：若正与目标处于**开战**状态，使节改为普通消耗（可召回）
3. 与目标同编号位置互换（庙堂对庙堂，或密室对密室）

> **禁止针对君主牌**：任何玩家的君主牌均免疫颁旨。

---

### 行动三：使节归朝

收回所有**非永久**消耗的使节代币。

---

### 行动四：宣国

**同时满足以下三项条件**方可宣国：

1. 庙堂**中央位置**有君主牌
2. 满足目标国家的**专属激活条件**（见第八章）
3. 目标国家**尚未被其他玩家宣认**

**宣国流程：**
1. 宣布目标国家名称
2. 其他玩家核实条件（密室条件须本人主动展示相关牌）
3. 核实通过后，取走对应国家令牌
4. 国家专属能力**即刻生效**
5. 庙堂中央位置**永久锁定**

**宣国不可逆**：宣国后不能放弃国家身份，锁定的中央位置无法改变。

**宣国失败**：若条件不满足，本回合白费。

---

### 行动五：称霸

触发游戏结算：
- 其余每位玩家**再各行动一轮**后进入结算
- **触发条件**：列国英才中已耗尽的位置数 ≥ 下表规定数量

| 人数 | 需耗尽叠数 |
|------|----------|
| 2 | 2 |
| 3–4 | 3 |
| 5–6 | 4 |
| 7 | 5 |

> 游戏结束时仍未宣国的玩家以白板状态参与计分，无任何国家加成。

## 八、七国设定

### 全局规则

- 所有玩家**白板起手**，无国家身份，无国家能力
- 每个国家至多一名玩家宣认，**先到先得**
- 宣国**不可撤销**，一旦宣国即永久绑定

---

### 七国激活条件与专属能力

| 国家 | 宣国额外条件（除君主位外） | 宣国后专属能力 | 历史意象 |
|------|--------------------------|--------------|---------|
| **秦** | 颁旨格有 ≥2 枚永久使节（累计颁旨 2 次） | 颁旨消耗的使节改为普通消耗（可召回） | 虎狼之国，强硬外交不伤己 |
| **齐** | 庙堂与密室合计持有 ≥5 种不同牌类型 | 每轮开始时可偷看任意对手密室的一张牌 | 稷下学宫，情报广博 |
| **楚** | 庙堂+密室合计有 ≥3 张农田 | 农田牌每张额外 +2 分 | 沃野千里，以丰养战 |
| **赵** | 密室中有 ≥2 张骑兵 | 骑兵牌得分翻倍 | 胡服骑射，精骑深藏 |
| **魏** | 当前有 ≥1 个结盟关系 | 宣国时立即获得 1 枚使节 | 信陵君礼贤下士，以盟为本 |
| **韩** | 庙堂+密室合计有 ≥2 张关隘 | 持有关隘牌不扣分（集齐仍可 +30） | 凭险自守，化险为夷 |
| **燕** | 密室中有 ≥4 种不同牌类型 | 游侠牌每个种类额外 +3 分 | 荆轲刺秦，奇人辈出 |

> **大棋盘平衡提示**：4–7 人游戏使用 7 或 9 格棋盘，建议将齐（≥5→≥6 种）和燕（≥4→≥5 种）的激活条件各上调一档。

---

### 宣国博弈情景举例

**争抢情景**：你正攒农田准备宣楚，对手庙堂里已有 2 张农田和君主牌——颁旨干扰对手庙堂，还是加速凑自己第 3 张，还是转向其他国家？

**阻断情景**：对手密室里据说有 2 张骑兵，下回合可能宣赵。颁旨可以换走一张密室牌，但会永久消耗一枚使节。值得吗？

**史书卡驱动**：开局摸到"胡服骑射"——骑兵翻倍，正好配合赵国能力，这把就定了赵国方向；还是先把史书卡放在一边，看看能不能更快宣其他国家？

**宣国的暴露**：一旦宣国，你的策略全部曝光。敌人知道你是赵国，会优先针对你的密室骑兵。宣国是必要的，但时机即是博弈本身。

## 九、外交系统：合纵连横

### 9.1 三种外交状态

| 状态 | 对颁旨的影响 | 其他效果 |
|------|------------|---------|
| **修好**（默认） | 正常颁旨（永久消耗使节） | 无 |
| **结盟** | 无法对盟友颁旨 | 可借用盟友使节执行附加行动 |
| **开战** | 对敌颁旨改为普通消耗（可召回） | 游戏结算时胜者 +5，败者 −5 |

### 9.2 状态转换

| 转变 | 方式 | 代价 |
|------|------|------|
| 修好 → 结盟 | 双方各消耗 1 枚使节，同时宣布 | 需**双方同意** |
| 结盟 → 修好（背盟） | 一方单方宣布 | 背盟方消耗 1 枚使节；**受害方 +3 分** |
| 修好 → 开战 | 任意一方在己方回合宣战 | 无即时代价 |
| 开战 → 修好 | 一方消耗 2 枚使节求和 | 需**对方同意** |

### 9.3 结盟共享使节

结盟状态下，可借用盟友的使节执行招贤纳士的附加行动（调位/清除）。借来的使节使用后归还盟友，不归你。

### 9.4 战争结算

游戏结束时，每对仍开战的玩家比较最终总分：得分较高方 **+5 分**，较低方 **−5 分**。

## 十、游戏结束与计分

### 10.1 结算流程

1. 称霸玩家宣告，其余玩家各再行动一轮
2. 所有玩家同时翻开密室
3. 计算庙堂与密室得分（含国家专属加成）
4. 执行战争结算
5. 计入玉璧补偿、背盟补偿等额外分项
6. 最高分者获胜

### 10.2 得分来源汇总

| 来源 | 规则 |
|------|------|
| 庙堂牌 | 按各牌规则计分（含国家加成） |
| 密室牌 | 按各牌规则计分（含国家加成） |
| 战争加成 | 胜者 +5，败者 −5 |
| 背盟受偿 | 被背盟时 +3 |
| 完璧归赵 | 玉璧被强制转移时 +5 |

### 10.3 平局裁决

总分相同时，依次比较：
1. 庙堂中不同种类牌的数量（多者胜）
2. 剩余使节代币数量（多者胜）
3. 骰子决定

## 十二、联机实现数据结构

```typescript
type Nation = '秦' | '齐' | '楚' | '赵' | '魏' | '韩' | '燕';
type DiplomacyStatus = '修好' | '结盟' | '开战';
type CardType =
  | 'Wasteland'   // 荒地
  | 'Farmland'    // 农田
  | 'Strategist'  // 谋士
  | 'Lord'        // 君主（免疫强制转移）
  | 'Cavalry'     // 骑兵
  | 'Banner'      // 旌旗
  | 'Pass'        // 关隘
  | 'City'        // 城邑
  | 'Wanderer'    // 游侠
  | 'JadeDisc';   // 玉璧

type ActionType =
  | 'Recruit'        // 招贤纳士
  | 'Decree'         // 颁旨
  | 'Recall'         // 使节归朝
  | 'DeclareNation'  // 宣国
  | 'Hegemony';      // 称霸

interface GameState {
  phase: 'lobby' | 'playing' | 'scoring';
  currentPlayerIndex: number;
  players: Player[];
  river: RiverSlot[];           // 5 / 7 / 9 格，与庙堂同规格
  courtSize: 5 | 7 | 9;        // 当前游戏棋盘规格
  diplomacy: DiplomacyMap;      // "秦-齐" → DiplomacyStatus
  claimedNations: Set<Nation>;  // 已被宣认的国家
  roundCount: number;
}

interface Player {
  id: string;
  nation: Nation | null;         // null = 尚未宣国
  court: Card[];                 // 庙堂（明阵），长度 = courtSize
  chamber: Card[];               // 密室（暗阵），长度 = courtSize
  centerLocked: boolean;         // 宣国后 true，庙堂中央位置永久锁定
  envoys: number;                // 可用使节数
  permanentDecrees: number;      // 颁旨格永久使节数
  historyCards: HistoryCard[];   // 史书卡（宣国前不可打出）
}
```
