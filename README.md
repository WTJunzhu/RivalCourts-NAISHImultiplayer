### 核心机制概述

每位玩家持有 **10 张牌**，分为明阵（5 张公开）和暗阵（5 张隐藏），各有位置编号 1–5。桌中央**河流**：5 个位置，每位置一叠，顶牌朝上，取走后下张翻开。

四大行动：发展（取牌替换）、颁布（永久消耗使者与对手互换）、召回（取回使者）、宣告（触发结算）。每人开局有初始手牌，需选一张传给对手。

## 二、设计理念

战国时期（公元前 475–221 年）天然适配本游戏：七雄并立对应 2–7 人人数，合纵连横对应外交博弈，招贤纳士对应核心发展机制，明堂与暗室的两面性对应明暗双区。

### 核心设计目标

1. **保留原版节奏**：回合快、决策精
2. **宣国是中期目标**：争抢君主牌、积累激活条件、抢先宣国，是游戏中段的主要张力
3. **宣国代价真实**：宣国暴露暗室、君主牌分数归零，白板流永远有竞争力
4. **史书卡是宣国奖励**：宣国前不可使用，驱动玩家根据手牌决定宣国方向
5. **使节是有限资源**：槽位占满则行动被锁死，召回时机本身就是博弈

## 五、核心组件

### 5.1 明堂（公开区）

每位玩家的明堂与英才同格数，所有牌面朝上，人人可见。初始全为荒地牌。

### 5.2 暗室（隐藏区）

与明堂同格数，牌面朝下，仅本人可见。初始 2 张随机基础牌 + 其余格位荒地（见第七章）。

### 5.3 列国英才（英才）

桌子中央公共牌池，与明堂同格数。每格一叠，顶牌朝上，取走后下张翻开。**君主牌只在英才中出现，不进入初始手牌。**

### 5.4 使节代币

每位玩家开局持有 **3 枚使节**，固定不随人数变化。使节是执行大多数行动的核心资源。

**使节放置规则**：需要使节的行动都有对应槽位。当某种行动的所有槽位被占满时，**任何人都无法再执行该行动**，直到有人召回使节腾出槽位。

### 5.5 使节槽位数量

| 行动 | 性质 | 小局 5 格 | 中局 7 格 | 大局 9 格 |
|------|------|---------|---------|---------|
| **交换** | 非永久 · 附加 | 3 | 4 | 5 |
| **弃牌** | 非永久 · 附加 | 2 | 3 | 4 |
| **出使** | 非永久 · 独占回合 | 2 | 3 | 4 |
| **号令** | **永久** · 独占回合 | 1 | 2 | 3 |

- **非永久**：可通过召回行动收回
- **永久**：使节永远留在槽上，任何情况下不可召回
- **召回行动本身不需要槽位**，只消耗一个回合

### 5.6 开战标记

公共展示区，记录当前哪些玩家对之间处于**开战状态**（含在途的出使）。初始所有人无状态。

### 5.7 七国令牌

场中央摆放 7 枚国家令牌（秦、齐、楚、赵、魏、韩、燕）。成功宣国后取走对应令牌。**被取走的令牌代表该国已被宣认，任何人不得再选。**

### 5.8 史书卡

每位玩家开局随机持有 2 张史书卡（初始传牌后确定，见第七章）。

> **核心限制：史书卡只有在宣国之后才能打出。** 开局即可查看，可用于规划宣国方向，但宣国之前无法使用。

## 六、卡牌设计

### 6.1 基础牌（9 种）

计分规则中所有位置描述均为相对描述，适用于 5、7、9 格三种规格：

**卡牌类型标记**（对应原版内侍实体牌设计）：
- **地形卡**（右上角六边形标记）：农田、关隘、城邑、旌旗
- **人物卡**（右上角矩形标记）：谋士、君主、骑兵、游侠
- **荒地**：无标记（不算作独立牌类型，不参与游侠计分）

| 牌名 | 颜色 | 计分规则 |
|------|------|---------|
| **荒地** | 白 | 持有 1 张 +5 分；2 张 −5 分；3 张以上 −15 分。**不在英才中出现**，仅用于初始填充空格位 |
| **农田** | 黄 | 计数相邻的农田卡，连两张牌+10分，三张+20分，四张及以上+30分 |
| **谋士** | 青 | 基础分 = max(2, 5 − D)；D = 谋士所在列与目标列的最近距离；目标列 = 君主列紧邻的左右两列；与**君主牌直接相邻**（含跨区上下相邻）额外 +6 分（详见 6.1.1） |
| **君主** | 金 | 明堂**中央位置**+12 分；其他位置 +4 分（特殊规则见下） |
| **骑兵** | 赤 | 仅在**暗室**得 +3 分；明堂中 0 分。如果在同一位置的明堂中有旌旗则自身由+3分变为+10分 |
| **旌旗** | 橙 | 计算明堂中的旌旗卡数量：一张+3分，两张+8分，三张及以上+15分 |
| **关隘** | 灰 | 持有 1 张 −5 分；2 张 0 分；3 张以上 +30 分 |
| **城邑** | 紫 | 在明堂或暗室**最左端或最右端**位置 +10 分；其他位置 −5 分；每有 1 张直接相邻（含跨区）的旌旗或骑兵额外 +4 分 |
| **游侠** | 绿 | 暗室中基础 +5 分，再加 5 × 暗室内不同牌类型总数（含游侠本身，**不含荒地**）；暗室其他牌正常按自身规则计分 |

---

### 6.1.1 谋士基础分参考

**目标列 = 君主列紧邻的左右两列**，暗室谋士与明堂谋士同规则（按列计算）。

| 场次 | 君主列 | 目标列 | 各列基础分（pos 1 → N） |
|------|--------|--------|----------------------|
| 5 格 | 3 | **2, 4** | 4 · **5** · 4 · **5** · 4 |
| 7 格 | 4 | **3, 5** | 3 · 4 · **5** · 4 · **5** · 4 · 3 |
| 9 格 | 5 | **4, 6** | 2 · 3 · 4 · **5** · 4 · **5** · 4 · 3 · 2 |

---

### 6.2 君主牌——特殊规则

1. **数量严格限定**：牌库中君主牌总数 = 当前玩家人数，每人最多持有 1 张
2. **免疫一切强制转移**：无法通过号令、史书卡或任何机制被强行转移
3. **宣国后分数归零**：宣国成功后，明堂中央的君主牌**不再计入得分**（+12 和 +4 均失效）
4. **宣国后位置锁定**：明堂中央位置**永久锁定**，不可再移动或替换

---

### 6.3 史书卡（8 种，宣国后才能打出）

每人开局随机持有 2 张，可替代常规行动使用，每张只用一次。
- 使用史书卡的行动默认消耗自己一个回合，若有特殊情况会在卡牌说明中特别标注，比如连横破盟卡满足条件时可以立即打出，不消耗回合。

| 史书卡 | 出处 | 效果 |
|--------|------|------|
| **合纵之盟** | 苏秦合纵六国 | 与任意玩家立即结成停战协议，**本轮结束前**双方均不可对对方出使或号令 |
| **连横破盟** | 张仪连横 | 当有人开战时（包括自己），可以选择立即打出，终止场上玩家的开战状态；与此同时，你从其中一方明堂取一张**非君主**牌放入己方明堂 |
| **围魏救赵** | 孙膑大梁之策 | 指定玩家 A 将明堂某**非君主**位置的牌交给玩家 B；若你这么做，你立刻进行一次招贤纳士操作（不占用自己的回合） |
| **负荆请罪** | 廉颇蔺相如 | 撤回你自己的一次正在传递中的出使（未生效的出使），该使节立即从出使槽回到你手中；被取消出使的目标玩家获得 +3 分补偿；撤回一事对所有人公开 |
| **远交近攻** | 范雎入秦 | 发动后，你与和你距离最远的玩家（若有多个玩家与你距离相同，取顺时针第一个）获得一次收回使节的机会，效果立即生效（跳过距离延迟）；同时选择与自己相邻一名玩家开战（正常延迟）；两次出使均不占槽位，不消耗使节 |
| **纵横家** | 苏秦/张仪双绝 | 本回合可执行两次常规行动（你打出此卡的回合不计算在内） |
| **反间计** | 战国间谍 | 选择两位玩家，让他们各自挑选一张暗室牌。如果他们选择的暗室牌位置不同，他们会互相展示选择的暗室牌，然后再向你展示；如果他们选择同一位置的暗室牌，则他们不需要展示，你需要向他们展示你暗室相同区域的牌；无论结果如何，你可马上额外执行一次招贤纳士 |
| **胡服骑射** | 赵武灵王 | 打出此卡后对所有其他玩家发动判定：如果他们的骑兵前面没有旌旗，则会在最终结算时扣除3分（数量可叠加）；如果他们的骑兵前面有旌旗则不受影响；若他们的骑兵压根就不在暗室，则会在最终结算时扣除5分（数量可叠加）。如果有玩家是赵国，则他不会执行此判定 |

## 七、游戏开局：初始发牌与传牌

### 7.1 初始发牌

游戏开始时，系统为每位玩家处理：
- **暗室**：在随机 2 个格位各放 1 张基础牌（非君主），其余格位放荒地
- **史书卡**：随机发 2 张
- 明堂全为荒地，英才正常展开，**君主牌只在英才中**

### 7.2 传牌（顺时针）

每位玩家查看自己的 2 张暗室牌和 2 张史书卡后，**必须强制选出 1 张暗室牌 + 1 张史书卡**，顺时针传给下一位玩家。所有人同时选好，一起交换。

接收到的牌占据被传出那张牌的格位，史书卡加入手牌。

传牌结束后，每位玩家暗室中有：
- 1 张自己留下的牌（原格位不变）
- 1 张上家传来的牌（占据己方被传出牌的格位）
- 其余格位：荒地
- 史书卡：共 2 张（1 自留 + 1 传入）

> **博弈点**：你能看到你传给下家什么牌，对方的暗室由此有了已知信息。选择传什么，也决定了自己暗室格位的布局。

## 八、六大行动

每回合，当前玩家从以下**六种行动中选择一种**：

---

### 行动一：招贤纳士

从英才中取一张牌，替换明堂或暗室**同编号格位**的旧牌（旧牌入弃牌堆）。

**可附加**（需相应槽位空余，消耗 1 枚使节）执行以下一项：

- **交换**：占用 1 个交换槽位。将以下任意一组的两张牌互换位置：
  - 己方暗室内任意两格
  - 己方明堂内任意两格
  - 英才内任意两格
  - 己方明堂某格与**对应编号**暗室格的牌（跨区同位互换）
- **弃牌**：占用 1 个弃牌槽位。弃掉英才中任意 2 叠的顶牌（翻出下层牌）

> 宣国后明堂中央格位永久锁定，不可被招贤纳士替换，也不可用于交换附加行动。

---

### 行动二：出使

向另一名玩家发起宣战：

1. 占用 1 个**出使槽位**（若全满则无法执行此行动）
2. 指定目标玩家，宣告**开战**
3. **延迟生效**：效果在 **N 个玩家回合后**触发，N = 两玩家在回合顺序上的最近距离

**开战生效时：**
- 服务器自动结算交战双方当前全部牌面（明堂 + 暗室）得分
- 公开宣布**胜负结果**，**不公开具体分数**
- 胜方在游戏**最终结算** +5 分，败方 −5 分
- 开战状态**立即解除**，恢复无状态
- 使节继续留在出使槽上，等待被召回（占住槽位直到玩家选择召回）

---

### 行动三：号令

> **前提：只有宣国后才能执行此行动。** 白板玩家永远不能使用号令，但可以成为目标。

1. 占用 1 个**号令槽位**（若全满则无法执行；号令槽位上的使节**永久不可召回**）
2. 在自己的明堂或暗室中选择一个格位的牌（**不可选已锁定的君主位**）
3. 与目标玩家**同区域（明堂↔明堂 或 暗室↔暗室）、同编号格位**的牌互换
4. **君主牌豁免**：若目标格位是君主牌，互换中止；**仅操作者**收到私密提示"该格位存在君主牌，请重新选择"，目标玩家和其他所有人均不知晓此次尝试

---

### 行动四：召回

消耗一个完整回合，将自己所有**可召回的使节**取回。

- 可召回：交换槽、弃牌槽、出使槽上的使节
- **不可召回**：号令槽上的使节（永久）
- 召回行动本身**不需要槽位，不消耗使节**

---

### 行动五：宣国

**同时满足以下三项方可执行：**
1. 明堂**中央格位**有君主牌
2. 满足目标国家的**专属激活条件**（见第九章）
3. 目标国家**尚未被他人宣认**

**宣国流程：**
1. 宣布目标国家
2. 其他玩家核实条件（暗室条件由本人主动展示相关牌）
3. 核实通过后，取走对应国家令牌
4. 以下四件事**同时发生**：
   - 国家专属能力**即刻生效**
   - 明堂中央君主牌**分数归零**（不再计入得分）
   - 明堂中央格位**永久锁定**
   - **暗室全部翻开**，所有玩家可见

> **宣国不可逆，史书卡解锁**：宣国后无法撤销；手中史书卡从此回合起可以打出。

**宣国失败**（条件不满足时宣告）：本回合白费，不执行任何其他行动。

---

### 行动六：称霸

> **前提：只有宣国后才能执行此行动。**

在己方回合，若英才**已耗尽叠数 ≥ 称霸门槛**，宣国玩家可选择发动称霸：

1. 宣告称霸（消耗本回合）
2. 其他每位玩家**各再行动 1 轮**——无论当前各玩家回合数是否已对齐，均补 1 轮
3. 进入最终结算

称霸门槛 = 强制结算叠数 − 1（见第四章表格）。

---

### 强制结算（被动，无需宣国）

> **术语**：**回合** = 每名玩家轮到自己时的一次行动（含史书卡等产生的额外行动）；**轮数** = 游戏层面的轮次计数，每位玩家各完成一个正常回合后加 1（额外回合不影响轮数）。强制结算以轮数对齐为标准，确保所有玩家进行相同次数的常规回合后再结算。

当任意玩家的行动导致英才**已耗尽叠数 ≥ 强制结算叠数**时触发：

- **本轮仍有玩家未行动**：让本轮剩余玩家依次完成行动（回合数对齐），之后立即结算，不再额外补轮
- **本轮所有玩家均已行动**（回合数已对齐）：立即结算，不补任何轮

> 例：三人场 ABC，A 在第 10 轮触发强制结算 → B、C 补完第 10 轮后结算（各 10 轮）。若改为 C 在第 10 轮触发 → A、B 已行动，三人回合数一致，立即结算。

> 游戏结束时仍未宣国的玩家以白板状态参与计分，无国家加成，暗室在结算时公开。

## 九、七国设定

### 全局规则

- 所有玩家**白板起手**，无国家身份，无国家能力
- 每个国家至多一名玩家宣认，**先到先得**
- 宣国**不可撤销**，永久绑定

---

### 七国激活条件与专属能力

| 国家 | 宣国额外条件（除君主位外） | 宣国后专属能力 |
|------|--------------------------|--------------|
| **秦** | 号令槽上有 ≥1 枚永久使节（已使用过号令至少 1 次）且当前自己没有任何空闲使节 | 号令槽上的使节改为可召回（不再永久），并且立即召回号令槽上的使节 |
| **齐** | 明堂与暗室合计持有 ≥7 种不同牌类型 | 每次自己回合开始时可选择是否要：偷看任意对手暗室的一张牌，但如果对同一个玩家偷看2/4/6/...次时，必须同时向该玩家主动展示自己的1/2/3/...张暗室牌（由自己挑选） |
| **楚** | 明堂+暗室合计有 ≥4 张农田 | 农田牌解锁新档位：相邻农田达到5张及以上，则+40分 |
| **赵** | 暗室中有 ≥2 张骑兵，且每个骑兵对应的明堂位置中都有旌旗 | 骑兵牌得分翻倍，由+10分变为+20分 |
| **魏** | 本局与其他玩家开战至少两次 | 宣国后开战变为消耗一个使节并在当前回合立刻开战，不再消耗回合；宣国时立即获得 1 枚**附加使节**，该使节只能用于交换或弃牌附加行动 |
| **韩** | 明堂+暗室合计有 ≥3 张关隘，且每个关隘至少与另一个关隘或者一个人物卡相邻 | 宣国后关隘牌所在位置不可被他人号令，且最终结算时，自己的每张地形卡（包括关隘自己）额外+2分 |
| **燕** | 暗室中有 ≥4 种不同牌类型且游侠处于暗室内 | 游侠牌最终结算时，每个种类额外 +3 分 |

> **平衡说明**：七国能力目前处于设想阶段，正式游玩测试后将根据实际情况调整。

## 十、外交系统

### 10.1 两种状态

| 状态 | 含义 |
|------|------|
| **无状态** | 默认，无特殊效果 |
| **开战** | 通过出使行动触发，延迟生效后进行中途结算 |

### 10.2 距离计算示例

5 人游戏，回合顺序 A→B→C→D→E（循环）：

| 宣战方 | 目标 | 最近距离 | 生效时机 |
|--------|------|---------|---------|
| A | B | 1 | 1 个回合后 |
| A | C | 2 | 2 个回合后 |
| A | D | 2 | 2 个回合后（另一方向 A←E←D） |
| A | E | 1 | 1 个回合后（A←E 方向） |

目标玩家在战争生效前有时间做出反应，这是"出使需要旅途时间"的设计意图。

### 10.3 史书卡对外交的干预

**负荆请罪**可立即结束开战、**远交近攻**可跳过距离延迟、**连横破盟**可干预他人战争，为外交系统引入变数。

## 十一、游戏结束与计分

### 11.1 结算流程

1. **触发方式**：
   - **主动称霸**：宣国玩家宣告称霸（消耗本回合），其余玩家无条件各补 1 轮后结算
   - **强制结算**：英才耗尽叠数达上限，本轮剩余玩家补完行动（对齐回合数）后立即结算；若触发时回合数已对齐则直接结算，不额外补轮
2. 所有玩家翻开暗室（未宣国的玩家此时才公开）
3. 计算所有玩家的明堂与暗室得分（含国家专属加成）
4. 计入所有中途开战结算的 +5/−5 分项
5. 最高分者获胜

### 11.2 得分来源

| 来源 | 规则 |
|------|------|
| 明堂牌 | 按各牌规则计分（含国家加成） |
| 暗室牌 | 按各牌规则计分（含国家加成） |
| 开战胜利 | +5 分（每次） |
| 开战失败 | −5 分（每次） |
| 负荆请罪受偿 | +3 分 |
| 宣国君主牌 | 0 分（已归零，不计） |

### 11.3 平局裁决

总分相同时依次比较：
1. 明堂中不同种类牌的数量（多者胜）
2. 剩余可用使节数量（多者胜）
3. 骰子决定

## 十三、可选功能模块

房主在开局前选择是否启用以下模块，未启用的模块视为关闭，对应规则不生效。

### 13.1 可选模块

| 模块 | 关闭后效果 |
|------|----------|
| **史书卡** | 不发史书卡；传牌阶段每人只传 1 张暗室牌（不传史书卡） |
| **出使/开战** | 取消出使槽位，无中途战争结算，无 +5/−5 分项；相关史书卡（远交近攻、合纵之盟、连横破盟、负荆请罪）效果均无效 |
| **七国专属能力** | 宣国仍可进行（抢占国家令牌、暗室翻开、中央锁定），但无国家能力；宣国后君主牌 **+12 分不归零** |

### 13.2 推荐预设

| 预设 | 史书卡 | 出使/开战 | 七国专属能力 | 适合场景 |
|------|--------|----------|------------|---------|
| 入门局 | ✗ | ✗ | ✗ | 初学，熟悉基础机制 |
| 标准局 | ✓ | ✗ | ✓ | 日常游玩推荐 |
| 完整局 | ✓ | ✓ | ✓ | 全员熟悉规则后 |

### 13.3 模块交互说明

- **史书卡关闭**：传牌只传 1 张暗室牌；宣国不再解锁史书卡
- **出使/开战关闭**：出使槽位从槽位表中移除，使节总量实际减少；外交相关史书卡即使在史书卡模块开启时也全部失效
- **七国专属能力关闭**：宣国代价依旧存在（暗室公开、君主位锁死），但 +12 分保留；宣国的意义变为"锁定君主位置 + 占领国家令牌 + 解锁史书卡（若开启）"；白板流与宣国流得分差距缩小，更接近平衡体验

## 十四、联机实现数据结构

```typescript
type Nation = '秦' | '齐' | '楚' | '赵' | '魏' | '韩' | '燕';
type CardType =
  | 'Wasteland'   // 荒地
  | 'Farmland'    // 农田
  | 'Strategist'  // 谋士
  | 'Lord'        // 君主
  | 'Cavalry'     // 骑兵
  | 'Banner'      // 旌旗
  | 'Pass'        // 关隘
  | 'City'        // 城邑
  | 'Wanderer';   // 游侠

type SlotType = 'Swap' | 'Discard' | 'Envoy' | 'Command';

interface SlotState {
  type: SlotType;
  totalSlots: number;
  occupants: string[];      // 占用该类型槽的玩家 id
  permanent: boolean;       // 号令槽为 true
}

interface WarRelation {
  playerA: string;
  playerB: string;
  turnsUntilActive: number; // 0 = 已生效
  winner?: string;          // 结算后记录
}

interface GameOptions {
  historyCards: boolean;    // 史书卡模块
  diplomacy: boolean;       // 出使/开战模块
  nationAbilities: boolean; // 七国专属能力模块
}

interface GameState {
  phase: 'lobby' | 'dealing' | 'passing' | 'playing' | 'scoring';
  currentPlayerIndex: number;
  players: Player[];
  river: RiverSlot[];
  courtSize: 5 | 7 | 9;
  slots: SlotState[];
  warRelations: WarRelation[];
  claimedNations: Set<Nation>;
  roundCount: number;
  options: GameOptions;
}

interface Player {
  id: string;
  nation: Nation | null;       // null = 白板
  court: Card[];               // 明堂，长度 = courtSize
  chamber: Card[];             // 暗室，长度 = courtSize
  centerLocked: boolean;       // 宣国后 true
  chamberRevealed: boolean;    // 宣国后 true
  envoys: number;              // 常规可用使节数
  bonusEnvoys: number;         // 魏国附加使节（只能用于交换/弃牌）
  historyCards: HistoryCard[]; // 史书卡（宣国前不可打出）
  warResults: number;          // 累计开战结算的 +/-5 分
}
```

## 十五、推荐实施路径

1. **第一阶段**：2 人基础联机（招贤纳士 + 交换/弃牌附加 + 号令 + 召回 + 称霸，9 种基础牌，君主牌规则）
2. **第二阶段**：开局发牌与传牌机制
3. **第三阶段**：宣国系统（条件核实、中央锁定、暗室翻开、分数归零逻辑）
4. **第四阶段**：3–7 人扩展（棋盘规格缩放、槽位表格、出使距离计算）
5. **第五阶段**：外交系统（出使延迟、中途结算、胜负记录）
6. **第六阶段**：史书卡机制（宣国后解锁打出）
7. **第七阶段**：七国专属能力 + 平衡测试
